# 🧾 Regras para Retirada de SET (PD)

> Regra interna para a **Staff do Prime Roleplayer** que atende pedidos de retirada de SET de organizações (PD).

### 1. Pedido de retirada somente pelo próprio player

* Apenas o **próprio jogador** que deseja retirar o SET pode fazer o pedido.
* **Gerentes não devem pedir em nome de terceiros.**
  * Caso isso aconteça, oriente o jogador **a fazer o pedido pessoalmente**.

***

### 2. Registro e entendimento do motivo do PD

* Sempre **entenda o motivo** pelo qual o jogador está pedindo a retirada do SET (PD).
* **Registre todas as retiradas** realizadas, com o motivo, para que a Gestão entenda o que está levando os players a pedir PD.

***

### 3. Evitar interferência entre facções

* **Líderes de facção não devem ir até outra facção** acompanhados de membros para pedir PD.
* Essa prática é **indevida** e gera atrito desnecessário entre as facções.

***

### 4. Respeitar o pedido do player

* Se o jogador **pediu para retirar o SET**, **não breque** o processo — **retire o SET**.
* Negar o pedido gera **insatisfação** e, em muitos casos, o jogador **não quer mais falar com o líder**.
* Nosso papel é **entender o que está acontecendo**, nunca impedir o processo.

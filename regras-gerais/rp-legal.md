# RP LEGAL

{% hint style="info" %}
**RP Legal** consiste em: Jurídico, Bombeiros, Mecânicos e Médicos.
{% endhint %}

{% hint style="danger" %}
**É proibido portar qualquer tipo de armamento ilegal.**

**Exceção:** caso possua **Porte de Arma**.
{% endhint %}

{% hint style="danger" %}
**Proibido qualquer tipo de ação ilegal.**
{% endhint %}

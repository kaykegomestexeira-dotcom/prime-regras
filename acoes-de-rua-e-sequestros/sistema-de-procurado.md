# SISTEMA DE PROCURADO

{% hint style="warning" %}
Ao efetuar qualquer tipo de roubo/ação, há **porcentagem de chance** de gerar um **procurado** no seu personagem.
{% endhint %}

{% hint style="warning" %}
Ao ficar procurado, você fica incapacitado de: **guardar itens em baús**, **efetuar outros roubos** e **trocar de roupa**.
{% endhint %}

{% hint style="warning" %}
Além disso, você passa a ficar **detectado no radar da polícia** com uma certa constância.
{% endhint %}

{% hint style="danger" %}
A polícia tem o poder de **abordar qualquer pessoa que considere suspeita** — no entanto, só pode **revistar** se o suspeito estiver **procurado**.
{% endhint %}

{% hint style="danger" %}
**A polícia NÃO pode entrar no perímetro da sua facção!**
{% endhint %}

{% hint style="danger" %}
Caso o procurado não tenha interesse em se entregar, ele deve seguir as regras de **DESCE E QUEBRA** ou efetuar **fuga limpa até o final**.
{% endhint %}

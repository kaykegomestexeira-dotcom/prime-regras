# DESCE E QUEBRA

{% hint style="success" %}
O desce e quebra é permitido em **áreas remotas**, exceto vias principais da cidade. **Proibido dar voz dropado.** Não é permitido desce e quebra **no asfalto** — apenas em **becos, vielas, garagens e interiores**.
{% endhint %}

{% hint style="success" %}
**Veículos voadores e blindados:** liberado o uso em locais de **dominação e assaltos de rua**, podendo atirar de dentro deles (quando possível) e também atirar contra eles. (Áreas de dominação: dentro do perímetro.)
{% endhint %}

{% hint style="danger" %}
**É obrigatório que seja iniciada uma fuga ANTES do desce e quebra.**
{% endhint %}

{% hint style="danger" %}
**Qualquer voz de assalto fora do carro está sujeita a punição imediata!**

Tempo de fuga de **5 minutos no mínimo**!
{% endhint %}

{% hint style="warning" %}
Caso o carro de quem está dando fuga **capote** (teto encoste no chão), ele é **OBRIGADO a se render** — caso contrário, é punido com **720 minutos de ilha**.
{% endhint %}

{% hint style="warning" %}
Caso o bandido **mate o policial no exato momento em que for abordado** (abordagem de rotina ou com suspeita fundada), será caracterizado como **RDM**.
{% endhint %}

{% hint style="warning" %}
Para prestar **QRR durante um desce e quebra**: é obrigatório que o QRR **participe da fuga também**, acompanhando o grupo.
{% endhint %}

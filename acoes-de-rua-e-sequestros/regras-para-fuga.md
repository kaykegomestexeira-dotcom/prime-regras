# REGRAS PARA FUGA

{% hint style="danger" %}
**É proibido, durante uma fuga, fugir para áreas safes ou para sua facção** para impedir que a ação aconteça.
{% endhint %}

{% hint style="danger" %}
**A fuga limpa deve ser priorizada até o final** — sem limite de tempo para terminá-la.
{% endhint %}

{% hint style="danger" %}
**Não é liberado disparo durante a fuga!**
{% endhint %}

{% hint style="warning" %}
Caso seu carro **capote** (bater no chão de cabeça para baixo), você deve **se entregar** e finalizar a fuga. (Podendo apenas **fugir a pé** após isso.)
{% endhint %}

{% hint style="warning" %}
**Não há limite de viaturas** em perseguições ou fugas.
{% endhint %}

{% hint style="info" %}
Em **fugas a pé**, é permitido apenas a **cabeçada** da polícia e o **taser** para evitar que o bandido fuja. Caso consiga usá-lo, pode **algemar**.
{% endhint %}

{% hint style="info" %}
É permitido **rampagens** durante a fuga.
{% endhint %}

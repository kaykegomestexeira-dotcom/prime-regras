# SEQUESTROS

{% hint style="warning" %}
⚠️ **Sequestro: apenas permitido nos horários de assalto!**

* **Bandidos:** mínimo 5 / sem limite.
* **Polícia:** máximo **+4** em relação aos bandidos.
* **É proibido dar voz de sequestro com menos de 5 integrantes no comboio.**
* Os bandidos são **obrigados a informar** (via chamado à polícia) **quantos estão e o local da negociação**. Em briga de facção, o sequestrado pode repassar pela **RÁDIO** as informações que o sequestrador determinar.
* **Armamento sem restrição.**
* A **integridade do refém deve ser sempre preservada**.
* **Servidores públicos** só podem ser sequestrados quando: **fora de serviço**, ou **fardados a pé fora de ação/abordagem**.
* O **valor máximo** que pode ser solicitado em um sequestro é **600.000**, independente de quantas cabeças sejam sequestradas!
* Caso bandidos ou polícia **efetuem disparos durante a negociação** ou pratiquem **metagaming**, a **Staff pode intervir**!
* **É proibido iniciar um sequestro em local onde já existe algum tipo de ação** (ex: Facções, Banco Central, Nióbio etc.). O sequestro deve começar em um local **sem nenhuma ação em andamento**. (Use a criatividade!)
  * Ex: usar alguém de isca para levar até um local onde estão os outros integrantes e iniciar o sequestro.
{% endhint %}

{% hint style="danger" %}
**É proibido, durante uma fuga, fugir para áreas safes ou para sua facção** para impedir que a ação aconteça.
{% endhint %}

{% hint style="success" %}
**A vida de cada refém pode ser negociada por 250k** (cada).
{% endhint %}

{% hint style="success" %}
Bandidos podem solicitar ajuda dos demais membros de sua organização e levar a fuga para um local estratégico, onde haverá trocação de tiros.
{% endhint %}

{% hint style="success" %}
A polícia **não é obrigada a aceitar propostas absurdas**. A negociação deve ser **flexível para ambos os lados**.
{% endhint %}

{% hint style="success" %}
Toda negociação passa a ser **área safe APENAS durante a negociação**.
{% endhint %}

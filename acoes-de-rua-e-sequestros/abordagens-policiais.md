# ABORDAGENS POLICIAIS

{% hint style="success" %}
É permitida a **abordagem de rotina** da polícia em todo o mapa **se houver suspeita**. (Esta abordagem é **proibida de conter revista**.)
{% endhint %}

{% hint style="warning" %}
A **revista** é permitida somente em casos onde o suspeito esteja **PROCURADO**.
{% endhint %}

{% hint style="warning" %}
Caso o abordado não queira parar e se render, deve seguir as regras do **DESCE E QUEBRA** ou seguir com **fuga limpa até o final**.
{% endhint %}

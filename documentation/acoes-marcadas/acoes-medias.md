# 🥈 AÇÕES MÉDIAS

{% hint style="info" %}
Não é necessário agendamento.
{% endhint %}

{% hint style="info" %}
Não há negociação.
{% endhint %}

{% hint style="warning" %}
Utilize pistolas. Fuzis só são permitidos se a polícia concordar.
{% endhint %}

{% hint style="warning" %}
Criminosos: mínimo de 4 participantes.

Criminosos: máximo de 8 participantes.

Polícia: máximo de 11 participantes.

A polícia deve manter a vantagem de 3 participantes.
{% endhint %}

{% hint style="danger" %}
Depois do tempo limite da ação, a polícia deve avançar se estiver em número igual ou superior ao dos criminosos.
{% endhint %}

{% hint style="danger" %}
Espere por até 10 minutos após a abertura do cofre.

Se a polícia não aparecer nesse período, os criminosos podem deixar o local.
{% endhint %}

# 🥇 AÇÕES GRANDES

{% hint style="danger" %}
Agende a ação com pelo menos 4 horas de antecedência.
{% endhint %}

{% hint style="danger" %}
A negociação é obrigatória.
{% endhint %}

{% hint style="warning" %}
Criminosos: mínimo de 10 e máximo de 20 participantes.

Polícia: até 5 participantes a mais que o número de criminosos.
{% endhint %}

{% hint style="info" %}
Todos os armamentos são permitidos.
{% endhint %}

{% hint style="info" %}
A polícia pode utilizar 1 helicóptero e 2 blindados.
{% endhint %}

{% hint style="danger" %}
Depois do tempo limite da ação, a polícia deve avançar se estiver em número igual ou superior ao dos criminosos.
{% endhint %}

{% hint style="danger" %}
É permitido manter até 5 criminosos do lado de fora.

Na ação de Nióbio, não é permitido ter participantes externos.
{% endhint %}

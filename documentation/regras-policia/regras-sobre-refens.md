# 🔗 Regras sobre Reféns

* Não utilize amigos ou integrantes da própria facção como reféns.
* Não roube os pertences do refém. Itens perigosos podem ser retirados temporariamente, mas devem ser devolvidos quando ele for liberado.
* O refém só pode ser utilizado para a negociação.
* Não mantenha uma pessoa inconsciente como refém, mesmo que ela seja reanimada depois.
* A tomada de reféns só é permitida durante os horários de assalto.

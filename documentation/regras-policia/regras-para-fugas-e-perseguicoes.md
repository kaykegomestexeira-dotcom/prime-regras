# 🚗 Regras para Fugas e Perseguições

* As perseguições não têm limite de duração.
* Não há limite de viaturas na perseguição.
* Se o veículo capotar, o envolvido deve se render ou continuar somente a pé. A regra vale para os dois lados.
* Quem cair de uma motocicleta deve se render ou continuar a pé.
* Nenhum dos lados pode utilizar kit de reparo durante a perseguição.
* Bloqueios devem deixar uma passagem possível para o veículo em fuga.
* É proibido fugir para áreas seguras ou organizações e também dar voz de prisão nesses locais.
* A polícia deve priorizar a prisão, evitando execuções e preservando o direito de defesa.

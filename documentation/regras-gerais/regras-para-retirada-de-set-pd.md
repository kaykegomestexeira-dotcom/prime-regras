# 🧾 Regras para Retirada de SET (PD)

{% hint style="warning" %}
**1. Pedido feito pelo próprio jogador**

* A retirada de SET/PD deve ser solicitada pelo próprio jogador.
* Líderes ou gerentes não devem pedir a retirada por outra pessoa. O interessado deve fazer o pedido diretamente.
{% endhint %}

{% hint style="info" %}
**2. Registro e entendimento do motivo**

* Entenda o motivo apresentado pelo jogador para sair.
* Registre a justificativa da retirada do SET/PD para manter o histórico e evitar dúvidas.
{% endhint %}

{% hint style="danger" %}
**3. Evitar interferência entre facções**

* Não vá à sede de outra facção acompanhado de integrantes para exigir a retirada de SET/PD.
* Evite pressões e interferências entre organizações durante o processo.
{% endhint %}

{% hint style="success" %}
**4. Respeito ao pedido do jogador**

* Respeite a decisão de quem deseja deixar a organização.
* Não impeça ou dificulte um pedido de retirada feito pelo próprio jogador.
* Conduza o processo de maneira respeitosa, sem criar conflitos desnecessários.
{% endhint %}

# 🔪 DESCE E QUEBRA

{% hint style="success" %}
O desce e quebra é permitido em becos, garagens, interiores e áreas afastadas. Não faça no asfalto ou em vias principais e não dê voz estando fora do carro.
{% endhint %}

{% hint style="success" %}
Veículos aéreos e blindados podem participar de dominações e ações de rua. É permitido atirar de ou contra eles quando a mecânica possibilitar; nas dominações, respeite o perímetro.
{% endhint %}

{% hint style="danger" %}
É obrigatório tentar fugir antes de iniciar um desce e quebra.
{% endhint %}

{% hint style="danger" %}
Não dê voz estando fora do veículo. A fuga deve durar pelo menos 5 minutos antes do desce e quebra.
{% endhint %}

{% hint style="warning" %}
Se o veículo capotar ou tocar o teto no chão, renda-se. O descumprimento pode gerar 720 minutos de ilha.
{% endhint %}

{% hint style="warning" %}
Matar um policial imediatamente ao receber uma abordagem, sem seguir a dinâmica da ação, caracteriza RDM.
{% endhint %}

{% hint style="warning" %}
O QRR precisa acompanhar a fuga antes de participar do desce e quebra.
{% endhint %}

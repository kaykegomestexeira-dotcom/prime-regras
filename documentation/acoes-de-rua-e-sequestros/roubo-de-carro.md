# 🏎️ ROUBO DE CARRO

{% hint style="danger" %}
**Furto não presenciado:** Se o furto não for presenciado, ou só for percebido depois do início da fuga, não é permitido atirar.
{% endhint %}

{% hint style="danger" %}
É proibido roubar veículos em áreas seguras.
{% endhint %}

{% hint style="success" %}
**Furto presenciado:** Quando o uso da lockpick for presenciado, pode haver reação com armas, respeitando as regras de armamento do Norte e do Sul.
{% endhint %}

{% hint style="success" %}
**Recuperação do veículo:** Na recuperação de um veículo em via pública, siga a dinâmica de fuga e desce e quebra, somente durante os horários de assalto.
{% endhint %}

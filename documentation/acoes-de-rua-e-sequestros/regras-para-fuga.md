# 🚗 REGRAS PARA FUGA

{% hint style="danger" %}
**Não entre em áreas seguras ou territórios de facções para impedir ou encerrar uma ação em andamento.**
{% endhint %}

{% hint style="danger" %}
**Priorize a fuga limpa, que não tem limite de duração.**
{% endhint %}

{% hint style="danger" %}
Não atire durante uma fuga limpa.
{% endhint %}

{% hint style="warning" %}
Se o veículo capotar, renda-se ou continue a fuga somente a pé.
{% endhint %}

{% hint style="warning" %}
A polícia pode utilizar um número ilimitado de viaturas na perseguição.
{% endhint %}

{% hint style="info" %}
Na fuga a pé, a contenção deve ser feita por cabeçada ou taser; a algema só pode ser aplicada após o taser.
{% endhint %}

{% hint style="info" %}
Rampagens são permitidas durante a fuga.
{% endhint %}

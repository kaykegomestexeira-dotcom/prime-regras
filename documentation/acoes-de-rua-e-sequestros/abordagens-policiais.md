# 🚨 ABORDAGENS POLICIAIS

{% hint style="success" %}
Abordagens de rotina podem ocorrer em todo o mapa quando houver suspeita, sem revista automática.
{% endhint %}

{% hint style="warning" %}
A revista só é permitida quando o abordado estiver procurado.
{% endhint %}

{% endhint %}

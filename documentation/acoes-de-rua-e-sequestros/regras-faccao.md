# 🚩 REGRAS FACÇÃO

{% hint style="danger" %}
**Perímetro da facção:** O perímetro protegido da facção corresponde apenas à área vermelha da polyzone. A proteção contra RDM vale nesse espaço; o restante é área de circulação normal.
{% endhint %}

{% hint style="danger" %}
**Disparos para fora da facção:** É proibido atirar de dentro para fora do perímetro. A infração pode gerar advertência ao jogador e, em caso de reincidência, à organização.
{% endhint %}

{% hint style="danger" %}
**Fuga para a facção:** Não entre na facção para escapar de uma ação em andamento. A advertência será aplicada ao envolvido; se houver participação da liderança, poderá atingir a organização.
{% endhint %}

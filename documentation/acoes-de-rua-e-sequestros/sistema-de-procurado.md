# 🚓 SISTEMA DE PROCURADO

{% hint style="warning" %}
Após um roubo, existe a chance de o personagem ficar procurado.
{% endhint %}

{% hint style="warning" %}
Enquanto estiver procurado, não acesse baús, inicie outros roubos ou troque de roupa.
{% endhint %}

{% hint style="warning" %}
O radar atualiza periodicamente a posição do procurado para a polícia.
{% endhint %}

{% hint style="danger" %}
A polícia pode abordar suspeitos, mas a revista depende de o jogador estar procurado.
{% endhint %}

{% hint style="danger" %}
A polícia não pode entrar no perímetro de facções para buscar um procurado.
{% endhint %}

{% hint style="danger" %}
Ao ser abordado, renda-se ou inicie uma fuga limpa; para desce e quebra, cumpra as regras específicas.
{% endhint %}

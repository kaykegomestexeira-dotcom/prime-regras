# 🔫 AÇÕES DE RUA E SEQUESTROS

{% hint style="danger" %}
**Não inicie trocas de tiros no asfalto ou nas vias principais.**
{% endhint %}

{% hint style="danger" %}
**É proibido assaltar ou sequestrar iniciantes, paramédicos e mecânicos.**
{% endhint %}

{% hint style="danger" %}
No Sul, as ações de rua devem utilizar pistolas; nas dominações, todos os armamentos são permitidos.

No Norte, todos os armamentos são permitidos.
{% endhint %}

{% hint style="warning" %}
QRR infinito, como tiroteios em rodovias ou nos sinais vermelhos, é proibido e resulta em advertência grave de 720 minutos de ilha.
{% endhint %}

{% hint style="warning" %}
Ações de blip — pequenas, médias e grandes — notificam a polícia automaticamente, sem necessidade de chamado.
{% endhint %}

{% hint style="warning" %}
Não assalte nem sequestre iniciantes, paramédicos ou mecânicos.
{% endhint %}

{% hint style="warning" %}
Não coloque veículos dentro dos locais de roubo.
{% endhint %}

{% hint style="info" %}
Atos ilegais, como roubos, furto de veículos ou matar alguém, podem deixar o personagem procurado e marcado no mapa da polícia por 10 minutos.

Enquanto estiver procurado, é permitido fugir da polícia até o temporizador exibido na tela terminar.
{% endhint %}

{% hint style="success" %}
Nas ações em blips, é permitida uma aliança.
{% endhint %}

{% hint style="success" %}
Recomenda-se gravar as ações para eventual análise da administração.
{% endhint %}

{% hint style="success" %}
Reforços da própria organização podem ajudar, desde que estejam posicionados estrategicamente.
{% endhint %}

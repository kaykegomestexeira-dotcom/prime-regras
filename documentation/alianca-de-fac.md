# 💍 ALIANÇA DE FAC

* Ações pequenas: alianças são permitidas em ações como lojas e bebidas, respeitando as regras da modalidade.
* Ações grandes: alianças são permitidas somente em incursões.
* Ações de rua: facções podem se unir ao dar ou receber voz de assalto e em QRR quando houver baixo contingente. Todos devem usar a mesma roupa.
* Sequestros: alianças entre facções são proibidas.

QRR:

Não realize ações perto de facções para evitar reforços ilimitados.

{% hint style="danger" %}
**Alianças entre facções são proibidas nos eventos da cidade.**
{% endhint %}

# AÇÕES GRANDES

{% hint style="danger" %}
Marcar com **pelo menos 4 horas de antecedência**.
{% endhint %}

{% hint style="danger" %}
**Negociação obrigatória.**
{% endhint %}

{% hint style="warning" %}
**Contingente**

* **Bandidos:** 10 a 20
* **Polícia:** até 5 a mais que os bandidos
{% endhint %}

{% hint style="info" %}
**Todas as armas.**
{% endhint %}

{% hint style="info" %}
É permitida a utilização de **1 águia e 2 blindados** pela polícia.
{% endhint %}

{% hint style="danger" %}
Após o tempo limite da ação, a polícia será **obrigada a rushar** se estiver em **número maior ou igual** em relação aos bandidos.
{% endhint %}

{% hint style="danger" %}
**Fora do local** são permitidos até **5 bandidos**.

(Exceto **Nióbio**, em que nenhum bandido é permitido fora.)
{% endhint %}

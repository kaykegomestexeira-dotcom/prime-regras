# AÇÕES MÉDIAS

{% hint style="info" %}
**Não precisa marcar.**
{% endhint %}

{% hint style="info" %}
**Sem negociação.**
{% endhint %}

{% hint style="warning" %}
**Apenas pistolas** (fuzil negociado, caso a polícia aceite).
{% endhint %}

{% hint style="warning" %}
**Contingente**

* Min. de bandidos = 4
* Max. de bandidos = 8
* Max. de policiais = 11
* Sempre **3 policiais a mais** que bandidos
{% endhint %}

{% hint style="danger" %}
Após o tempo limite da ação, a polícia será **obrigada a rushar** se estiver em **número maior ou igual** em relação aos bandidos.
{% endhint %}

{% hint style="danger" %}
O **tempo máximo de espera** dos bandidos após estourar o cofre é de **10 minutos**.

A polícia não chegando nesse tempo, os bandidos poderão **fugir do local**.
{% endhint %}

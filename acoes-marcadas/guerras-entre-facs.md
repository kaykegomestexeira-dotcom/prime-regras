# GUERRAS ENTRE FACS

{% hint style="danger" %}
As guerras devem ser **marcadas com os membros das Orgs e Facs com pelo menos 1 dia de antecedência**.
{% endhint %}

{% hint style="info" %}
**Todas as armas** são liberadas **no perímetro** das organizações envolvidas na invasão/guerra.
{% endhint %}

{% hint style="success" %}
São liberadas **invasões aos QGs** das organizações envolvidas (agendadas e feitas no **mundo Evento**, com supervisão da **Prefeitura**).
{% endhint %}

# Regras sobre Reféns

* É **proibido utilizar membros da própria facção ou amigos como reféns**.
* O uso de reféns deve seguir o **RP de sequestro**. **Roubo de reféns é proibido** — é permitido retirar objetos que possam trazer perigo para os membros da facção, mas será **obrigatória a devolução dos itens** no momento da liberação dos reféns.
* Reféns servem **apenas para negociação na ação**. É proibido utilizá-los para outras finalidades.
* É **extremamente proibido pegar pessoas desmaiadas para serem reféns** — mesmo que use adrenalina ou chame médico, não será permitido.
* **É permitido o sequestro apenas nos horários de assalto!**

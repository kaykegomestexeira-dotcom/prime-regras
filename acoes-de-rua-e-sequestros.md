# AÇÕES DE RUA E SEQUESTROS

{% hint style="danger" %}
**PROIBIDO TROCAÇÃO DE TIRO NO ASFALTO!**
{% endhint %}

{% hint style="danger" %}
**É proibido sequestrar ou roubar iniciantes, paramédicos e mecânicos.**
{% endhint %}

{% hint style="danger" %}
Assaltos e abordagens **no Sul** podem ser feitas **apenas com pistola** — porém, dentro das **áreas de dominação**, todas as armas são liberadas!

No **Norte**, todas as armas são liberadas tanto para assalto quanto para abordagem.
{% endhint %}

{% hint style="warning" %}
A cidade preza pelo RP: ações de **QRR infinito** (tiroteio em rodovia e nos semáforos) ocasionam **advertência grave de 720 minutos na ilha**.
{% endhint %}

{% hint style="warning" %}
**Ações blipadas** (pequenas, médias e grandes) geram **aviso automático para os policiais** — não é necessário chamar a polícia.
{% endhint %}

{% hint style="warning" %}
É proibido **entrar com veículos nos locais de roubo**.
{% endhint %}

{% hint style="info" %}
**Sistema de PROCURADO:** ao cometer um ato ilegal (roubo, roubo de carro, homicídio) você fica **procurado** e marcado no mapa para a polícia por **10 minutos**.

Quando está procurado, você pode **dar fuga da polícia** até o tempo exibido na tela acabar.
{% endhint %}

{% hint style="success" %}
É permitida a **aliança de Facs/Orgs** para efetuar ações de blip, **limitada a 1 aliança**.
{% endhint %}

{% hint style="success" %}
É **recomendável** que todos os participantes das ações tenham **gravações**, para evitar problemas futuros.
{% endhint %}

{% hint style="success" %}
Bandidos podem **solicitar ajuda dos demais membros de sua organização** e levar a fuga para um local estratégico, onde haverá trocação de tiros.
{% endhint %}

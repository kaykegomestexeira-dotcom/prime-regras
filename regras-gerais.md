# REGRAS GERAIS

{% hint style="success" %}
**SEJA GENTE BOA.** Seja educado e trate bem os outros jogadores, principalmente os iniciantes.
{% endhint %}

{% hint style="warning" %}
QUALQUER ABUSO DE PODER É BANIMENTO!
{% endhint %}

{% hint style="success" %}
**Tenha amor à vida do seu personagem e dos outros.**

É obrigatório valorizar a vida do seu personagem como se fosse a única, fazendo tudo que for possível para não colocá-la em risco — **principalmente durante interações com outros jogadores.**
{% endhint %}

{% hint style="danger" %}
**Proibido Zaralho**

Qualquer tipo de bagunça que prejudique a cidade ou incomode outros players.
{% endhint %}

{% hint style="danger" %}
**PARA OCORRER DESCE E QUEBRA É NECESSÁRIO QUE ANTES OCORRA FUGA!**
{% endhint %}

{% hint style="danger" %}
**PROIBIDO DAR VOZ FORA DO CARRO. É OBRIGATÓRIO QUE OCORRA FUGA ANTES DO DESCE E QUEBRA.**
{% endhint %}

{% hint style="danger" %}
**Proibido Matar sem Motivo (RDM).**
{% endhint %}

{% hint style="danger" %}
**Proibido usar veículo como arma (VDM).**
{% endhint %}

{% hint style="danger" %}
**Proibido desconectar do servidor enquanto estiver envolvido em uma ação (CL).**
{% endhint %}

{% hint style="danger" %}
**Proibido desrespeito com outros jogadores (Dark RP)**

Todo tipo de discriminação: homofobia, racismo, abuso sexual etc.
{% endhint %}

{% hint style="danger" %}
**Proibido uso de bugs ou programas ilícitos**

Abusar de **BUGS/GLITCHS** ou usar **programas externos** para obter vantagens.

Proibida a utilização do ReviOS ou de qualquer outra versão de Sistema Operacional modificado.
{% endhint %}

{% hint style="danger" %}
**Windows Defender desinstalado levará a um banimento.**
{% endhint %}

{% hint style="danger" %}
**Proibido lembrar de eventos passados depois de morto.**

Depois que seu personagem morrer para outro jogador, todos os acontecimentos anteriores à morte devem ser esquecidos. Uma nova história começa após renascer.
{% endhint %}

{% hint style="danger" %}
**É proibido qualquer desrespeito com a cidade ou divulgação de outros servidores.**
{% endhint %}

{% hint style="danger" %}
**É proibido cometer caixa 2 em qualquer organização da cidade.**
{% endhint %}

{% hint style="danger" %}
**Todos os envolvidos na criação de uma nova cidade estão passíveis de banimento após análise da Alta Cúpula!**
{% endhint %}

{% hint style="danger" %}
**A apologia a cheats ou qualquer prática semelhante é passível de banimento!**\
**Qualquer envolvimento com cheats é banimento!**
{% endhint %}

{% hint style="danger" %}
**No Sul é permitido apenas pistolas normais** (ex: Five Seven, Glock e M1911). Qualquer pistola de cadência maior, como a Tec-9, é **estritamente proibida!**
{% endhint %}

{% hint style="success" %}
Ao receber voz você tem duas opções:

1. **Se render** — é obrigado a seguir o RP da abordagem ou do assalto;
2. **Dar fuga** para um local isolado/remoto e realizar o desce e quebra (só é permitido desce e quebra **após** a fuga!).
{% endhint %}
